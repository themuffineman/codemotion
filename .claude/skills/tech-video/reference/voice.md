# Script voice

Use this for every script written for a video in this repo, long or short.

## The voice

Write it the way you'd explain something to a friend you've known for years. Keep it friendly and casual, and say things as they are. The goal is for the viewer to understand the idea, so let the idea be interesting on its own instead of trying to make it sound exciting.

## Avoid

- **Hype.** Don't try to pump people up. Words like "insane", "mind-blowing", "massive", "genius" and "magic" are out, and so are lines like "this is my favorite part" or "it's so clever it's annoying".
- **Exaggeration.** If a number or claim isn't true as stated, soften it or cut it. Don't call something instant if it takes a second.
- **Rapping rhythm.** Don't stack short punchy fragments one after another, like "Song, artist, album. Done." or "Picture, stars, pairs." Write in full, normal sentences joined with "and", "so" and "because", the way people actually talk.
- **Lists of three.** Don't group things in threes for rhythm. If there are really three things, that's fine, but don't reach for a triplet because it sounds good.
- **"It's not X, it's Y" contrasts.** This includes variations like "Not the audio. Just the numbers.", "That doesn't work. Not even close." and "Not all of them. Enough of them." Say the true thing directly.
- **Repeating for emphasis**, like "Every single one." or "Really, really".
- **Section titles or headers inside the script.** The script is just the words to be spoken, as plain paragraphs.
- **Em dashes.**

## Format

The script is a plain `script.txt` of spoken paragraphs, like `src/videos/jvm/script.txt`. Visual notes go in a separate file so the script reads cleanly.
